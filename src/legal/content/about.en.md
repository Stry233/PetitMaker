# About {app}

{app} is an **unofficial**, fan-made map-planning tool for the game *Petit Planet*. It is not made or operated by the game's publisher, and it speaks only for its own small team.

## Mission

{app} lets you plan a map in your browser, laying out terrain, water, roads, and objects on the same grid the game uses. The editor is designed to produce layouts that you can reproduce in *Petit Planet*.

{app} began as a small volunteer effort by players who wanted to plan and revise a build before recreating it in the game. It remains a non-commercial fan project maintained in the team's spare time.

## Technology

{app} is a browser application built with TypeScript, React, PixiJS (for the 2D editor), and three.js (for the 3D preview).

**How it works.** The tool is a static, single-page application with **no user accounts and no backend that receives or stores maps**. Your maps are held locally, in your browser's storage and in the files you choose to export. The optional AI Agent and provider-backed illustration studio use API keys you supply and send requests directly from your browser to the provider you choose. Procedural and on-device illustration styles run locally. The [Privacy Policy](/privacy) explains these data flows.
