# 隐私政策

## 概览

本概览仅为便于阅读而提供，不取代下文各编号条款所载的完整政策。{app} 是一款完全运行于浏览器端的地图规划工具。它不设用户账户，项目运营方也**不使用服务器存储你的地图项目**；地图保存在你的浏览器中以及你自行导出的文件里。我们不展示广告，不设置广告 Cookie，也不进行跨站或跨设备追踪。可选的 AI 智能体与在线插画生成功能会使用你提供的 API 密钥连接第三方 AI 服务；本地插画风格不会联系 AI 服务提供商。部分分享图片的导出会**嵌入你的地图数据**，使收到图片的任何人都能据此还原该地图，详见[第 4 条](#4-分享图片)。本工具由 {operator} 运营；如有疑问，可发送邮件至 {email}。

## 1. 定义

本政策全文中，下列词语按此处所给含义使用。它们在此统一定义，以便下文各条款保持简洁。

- **「本服务」「本工具」「本应用」或「{app}」**指 {app} 网页应用及随附的静态页面，通过[第 13 条](#13-数据去向)所述的地址提供。
- **「我们」**指 {operator}，即[第 18 条](#18-联系我们与投诉)所标识的运营方，作为发布并维护本工具的一方。
- **「你」**指使用本工具的人。
- **「本地数据」**指应用在你自己设备的浏览器中保存的信息，其明细见[第 3 条](#3-我们存储的内容)。除非你主动导出或传输，否则它不会离开你的设备。
- **「地图」或「地图项目」**指你在编辑器中布置的地形、水域、道路、物件、规划标注（包括你输入的文字）及其他内容。
- **「分享图片」**指本工具从地图导出的图片。**可导入的**分享图片嵌入了足以还原该地图的数据；普通的、不可导入的导出则不含此类数据。分享图片见[第 4 条](#4-分享图片)。
- **「AI 智能体」**指可选功能，它会将你的提示词和地图数据发送给你所选择的 AI 服务提供商，详见[第 6 条](#6-ai-服务提供商自带密钥)。
- **「插画工作室」**指可选的导出功能，可以在你的设备上重绘地图，也可以通过你选择的 AI 服务提供商重绘地图，详见[第 6 条](#6-ai-服务提供商自带密钥)。
- **「AI 服务提供商」**指你为其提供 API 密钥、并由 AI 智能体或在线插画生成功能向其发送请求的第三方服务。AI 服务提供商并非我们，也不是本政策的一方。
- **「个人信息」**指在适用法律将其视为个人信息的范围内，能够识别、关联到某一可识别个人，或可合理与之关联的信息。
- **（基础设施的）「提供商」**指代表我们进行托管、分发或以其他方式处理信息的第三方，例如我们的托管、边缘、CDN 或电子邮件提供商。

## 2. 适用范围与我们不做的事

本政策说明 {app} 会处理哪些信息、这些信息可能存在于何处，以及你可以作出的选择。本政策适用于 {app} 网页应用及随附的静态页面。它不适用于你通过本工具触达的任何第三方服务，包括你所选择的 AI 服务提供商，或你通过外部链接打开的站点；这些服务受其各自的政策约束（见[第 12 条](#12-第三方链接)）。

{app} 不设置用户账户、注册流程或用户画像。它不展示广告，不设置广告 Cookie，不进行跨站或跨设备追踪，也不出售个人信息。由于本应用没有用于存储地图的后端，它所处理的信息相对有限。下文各条款逐一列明各类信息及其所在之处。

## 3. 我们存储的内容

应用所记住的绝大多数内容都作为**本地数据**保存在你的浏览器中，除非你主动导出或传输，否则不会离开你的设备。仍有一组有限的信息可能存在于你的设备之外，这主要是因为你将其发送到了某处，或是因为我们的基础设施记录了一次普通请求。本条逐类列明：它包含什么、何时写入，以及如何移除。

### 3.1 保存在你设备上的信息

此类信息包括下列各项。每一项说明该数据包含什么、在何时写入，以及你如何移除它。

- **自动保存的地图。**其包含：你正在编辑的当前地图项目（经紧凑编码），连同恢复它所需的少量编辑器状态。写入时机：在你更改地图后不久自动写入，且仅在地图已有内容时才写入，因此一张全新的空白地图绝不会覆盖已保存的地图。移除方式：换一颗星球、清除浏览器的站点数据，或使用「设置」中的「本地数据」（[第 5 条](#5-本地数据与清除本地数据)）。
- **你的偏好设置。**其包含：语言、界面缩放级别等界面设置；AI 智能体的提供商、模型、端点与监督方式；以及插画工作室的提供商、模型、端点、风格方向与自定义提示词。API 密钥另见下条。写入时机：在你更改相应设置时。移除方式：清除浏览器的站点数据，或使用「设置」中的「本地数据」。
- **你的 AI 智能体会话。**其包含：用于在页面重新载入后恢复智能体面板的指令、智能体回复、工具结果、计划、授权答复，以及已归档记录和已清除记录的编号。清除记录会从浏览器存储和智能体后续请求中删除该记录的对话内容及受影响的对话摘要。提供商原始响应数据与工具结果中的图片不会保存，推理内容仅保留简短摘录。写入时机：会话内容发生变化时。移除方式：在智能体面板中清除单条记录或历史任务、新建 AI 智能体会话、清除浏览器的站点数据，或使用「设置」中的「本地数据」。
- **API 密钥。**其包含：你为 AI 智能体或插画工作室输入的 API 密钥。写入时机：连接 AI 智能体时，其密钥会保存在本地；插画工作室仅在浏览器密钥保管库能够封存密钥时才会保存，否则只在本次会话的内存中保留。在浏览器支持时，密钥会封存于 IndexedDB 密钥保管库中；若该保管库不可用，AI 智能体会以轻度混淆形式保存密钥，插画工作室则不会写入密钥。移除方式：在 AI 智能体设置中移除密钥、清除浏览器的站点数据，或使用「设置」中的「本地数据」（该操作同时清除密钥保管库）。相关保护措施与限制见[第 7 条](#7-api-密钥)与[第 8 条](#8-安全措施)。

清除浏览器的站点数据，或使用「设置」中的「本地数据」，即可移除上述信息，详见[第 5 条](#5-本地数据与清除本地数据)。

### 3.2 可能存在于你设备之外的信息

尽管项目运营方不使用服务器存储你的地图项目，仍有少量信息可能存在于你的设备之外。下列各项说明它是什么、何时产生，以及你可以如何限制或移除它。

- **托管、CDN 与安全日志。**其包含：诸如 IP 地址、所请求的资源、时间戳与 user-agent 字符串等普通请求元数据，用于提供站点服务并防范滥用。产生时机：每当你的浏览器获取站点文件时。如何限制：它们由我们的托管平台和边缘平台创建，并受其政策与保留期约束（[第 13 条](#13-数据去向)与[第 14 条](#14-数据保留)）；本项目不另行运营应用日志服务。
- **聚合的、无 Cookie 的分析数据。**其包含：如果托管平台或 CDN 平台提供此类数据，则为不含广告 Cookie 与跨站标识符的聚合流量数据，详见[第 9 条](#9-数据分析与同意)。产生时机：作为该平台分发服务的一部分。
- **邮件与报告。**其包含：你写给我们的任何内容，包括你选择包含的任何细节。产生时机：在你发送时。移除方式：向我们提出请求，受[第 16 条](#16-你的权利)约束。
- **AI 智能体请求。**其包含：你的提示词、地图数据或快照，以及智能体所运行工具的结果。产生时机：在你主动调用智能体时；[第 6 条](#6-ai-服务提供商自带密钥)所述的密钥校验与模型列表请求除外，这类请求不含地图数据或提示词。如何限制：不连接或不使用智能体；对于已经发送的记录，请向提供商咨询删除方式。请求受该提供商约束，而非受我们约束。
- **在线插画生成请求。**其包含：当前地图的渲染图、风格指令、由应用生成的场景摘要，以及在提供商支持时附带的内置风格示例，或你此前选择保留的同一地图插画。产生时机：在你请求在线生成插画时；输入密钥后进行的模型列表或连接检查除外。本地风格不会发出提供商请求。如何限制：使用本地风格，或不连接插画工作室；对于已经发送的记录，请向提供商咨询删除方式。
- **你有意发布到第三方服务的图片或文件**，例如你将导出的图片分享到某处时。产生时机：在你发布时。移除方式：如你发布到的服务允许移除，则通过该服务移除。
- **可导入分享图片中嵌入的数据**，包括地图与规划标注，详见[第 4 条](#4-分享图片)。

## 4. 分享图片

应用会在新增文字出现在图片预览或导出结果之前，在本机检查标题、描述和页脚。导出 JSON 文件时，如果启用了备注，也会以同样方式检查标题、描述和作者。检查使用随应用提供的第三方词语匹配包及衍生的政治话题匹配数据，不下载 AI 模型。新增文字中的网站链接也会在本机检查，应用不会访问这些链接。文字不会为此上传，检查功能也不会单独保存文字或检查结果。匹配程序和临时数据可在内存中保留至空闲三十秒，以加快后续检查；关闭面板会清除这些数据。修改文字、关闭面板或取消导出会停止当前检查。你也可以选择不附加文字导出。

在显示图片导出预览之前，以及你请求导出 JSON 时，应用还会检查在本机绘制的地图画面。检查所需的图像分类和文字识别模型从应用所在的网站下载，并在你的设备上运行。地图图片和识别出的文字不会因此上传或另行保存。模型文件可能保留在浏览器的 HTTP 缓存中；临时分析数据会在检查结束或取消后释放。检查可能出现遗漏或误判，未能完成的检查会在导出面板中说明。

可导入的分享图片带有一条可见的 PetitGlyph 色带。色带中包含地形、水域、道路、物件和规划标注，包括标注文字以及标注图层的显示与锁定状态。此外，色带还可能包含生成参数、导出标题与时间、应用和文件格式版本，以及地图是否使用过 AI 或程序生成的标记。收到图片的人可以使用这些数据在 {app} 中还原相应地图。

**「显示标注」**只控制是否在导出的地图画面上绘制规划标注，不会从可导入的 PetitGlyph 中移除标注。如需仅导出画面、不附带可恢复的 PetitGlyph 数据，请关闭「可导入性」或选择普通图片。PetitGlyph 数据编码在可见像素中，因此清除常规文件信息并不能移除这些数据。

因此，你应像对待底层地图文件那样对待可导入的分享图片，仅将其分享给你愿意让其打开你地图的人。此种嵌入是该文件的一项技术特性，而非我们在服务器上进行的处理：图片在你的浏览器中生成，其所披露的内容取决于你将它发送给谁。

## 5. 本地数据与「清除本地数据」

「设置」中的「本地数据」命令会删除当前浏览器中存储的 {app} 数据，包括自动保存的地图、你的偏好设置、AI 智能体会话、所有已存储的 API 密钥，以及浏览器保管库密钥。该操作完全在你的设备上进行。

该命令**不会删除**下列内容，它们或不受我们控制，或已超出当前浏览器的范围：

- 你已经下载或导出的文件；
- 你已经分享或发布的图片；
- 浏览器或设备的备份，包括浏览器数据的云同步；
- 托管、CDN 或安全日志；
- 你已经发送给我们的邮件或报告；
- 你通过 AI 智能体或插画工作室使用的 AI 服务提供商所保存的记录；
- 任何其他人已经制作的、你的地图或图片的副本。

由于该命令仅清除当前设备上的当前浏览器，如果你的目的是不留下任何本地数据，则应在你使用过本工具的每一个浏览器和每一台设备上分别运行它。

## 6. AI 服务提供商（自带密钥）

AI 智能体与插画工作室的在线生成功能均以「自带密钥」方式提供。你需要自行提供 API 密钥，请求会从浏览器直接发往你选择的提供商。本政策说明应用会传输哪些内容；提供商如何处理和保留这些请求，则受**你与该提供商之间的协议及该提供商自身的政策**约束。使用前，请查阅这些文件。

各提供商及不同服务档位的数据处理方式可能不同。部分免费或未付费的 API 服务可能会将输入与输出用于改进产品，或允许人工审核；付费或企业服务可能适用不同规则。本应用无法仅凭密钥判断其所属服务档位或适用合同。

### AI 智能体

当你主动调用 AI 智能体时，它可能向所选提供商发送你的提示词、地图数据或当前地图的快照，以及工具结果。**在你主动触发之前，不会有携带你的地图数据或提示词的请求发出。**当你输入或校验密钥，或在已有密钥的情况下打开智能体时，应用可能联系所选提供商；如果无法确定密钥归属，也可能联系候选提供商，以校验密钥并列出可用模型。这类连接请求会使用密钥进行身份验证，但不含地图数据或提示词。

在连接设置与模型管理期间，AI 智能体还会从 **Models.dev** 下载公开的模型能力信息。这类请求不携带 API 密钥、提示词、地图数据或 Cookie。Models.dev 会接收 IP 地址等常规网络请求元数据。应用会在内存中保留近期副本，模型目录暂时不可用不会阻止使用。

## 7. API 密钥

连接 AI 智能体时，其密钥会保存在你的设备本地，以免反复输入。插画工作室仅在浏览器密钥保管库能够封存密钥时才会保存，否则只在本次会话的内存中保留。本地保护**无法**抵御被攻陷的浏览器、扩展、脚本或设备：在浏览器中执行的代码可能读取已存储的密钥，也可能在你输入时截取密钥。

在浏览器支持时，已存储的密钥会使用浏览器内不可导出的密钥进行静态封存。若保管库不可用，AI 智能体保存的密钥仅经过轻度混淆，插画工作室则将密钥留在会话内存中，不写入存储。密钥只会发送给你选择的提供商；在识别 AI 智能体密钥归属时，也可能发送给候选提供商。具名提供商均使用 HTTPS；只有在你自行配置时，自定义本地回环端点才可能使用 HTTP。密钥绝不会发送至项目运营的服务器。在共用或公共设备上，用完后请使用「设置」中的「本地数据」。

## 8. 安全措施

本服务采用下列技术措施。[技术威胁模型]({repo}/blob/main/docs/THREAT_MODEL.md)说明这些措施的适用范围与局限；[安全政策](/security)说明如何报告安全漏洞。

- **加密传输。**站点与具名提供商的请求使用 HTTPS；生产环境的边缘设置了 HTTP 严格传输安全（HSTS）。只有你明确配置的自定义本地回环端点才可能使用 HTTP。
- **严格的内容安全策略（CSP）。**应用将脚本限定为站点自身来源，并将网络连接限制为站点功能、提供商 API、使用 HTTPS 的自定义端点与本地网关。
- **在支持时对 API 密钥进行静态封存。**如[第 7 条](#7-api-密钥)所述，在浏览器支持时，已存储的密钥会使用不可导出的浏览器密钥进行封存；应用显示或保存的提供商错误文本也会移除形似密钥的内容。
- **没有地图存储后端。**项目不运营任何接收或存储你地图项目的应用后端。

这些措施无法保护自身已经被攻陷的设备上的数据。恶意软件、恶意浏览器扩展或能够接触设备的其他人，可能读取本地数据或在输入时截取密钥。在共用或公共设备上，用完后请清除本地数据。

## 9. 数据分析与同意

本应用不实施广告分析，不设置广告 Cookie，也不进行跨站追踪。托管平台或 CDN 平台可能会在提供站点分发与滥用防护时提供聚合的、无 Cookie 的流量数据。

如果我们的分析实现方式发生变化，同意机制**将重新评估**，并相应更新本政策。对于任何特定司法辖区是否需要取得同意，我们不作绝对化的断言。

## 10. 请勿追踪与全球隐私控制

某些浏览器可以发送「请勿追踪」（DNT）标头或「全球隐私控制」（GPC）信号。{app} 不进行跨站或跨设备追踪，不设置广告 Cookie，不出售个人信息，也不将个人信息用于跨情境行为广告，因此这些信号不会改变我们当前的处理方式。若我们的做法今后发生变化，使任一信号与本工具相关，我们会更新本条并说明处理方式。

## 11. 自动化决策

我们不使用自动化处理来作出对你产生法律效果或类似重大影响的决策。我们不建立画像、不分配评分，也不针对你运行任何自动化的资格、定价或排序决策。

AI 智能体与插画工作室均在你的指示下生成创作内容。其输出由你请求并审阅，不是我们对你作出的决定，也不会影响你获得的任何权利、访问权限或待遇。AI 服务提供商对请求的处理受该提供商约束（[第 6 条](#6-ai-服务提供商自带密钥)）。
