# 联系我们

有使用问题、改进建议或需要我们处理的事项，可以通过以下渠道联系团队。我们争取在 14 天内回复；志愿团队繁忙时可能需要更久。依法需要在特定期限内答复的请求，会按相应要求处理。

| 事项 | 渠道 |
| --- | --- |
| 使用问题、错误报告和建议 | [GitHub 问题反馈]({repo}/issues)或 {email} |
| 安全漏洞 | {securityEmail}，邮件主题注明 `[SECURITY]` |
| 素材授权或知识产权投诉 | {email}，邮件主题注明 `[IP]` |
| 内容检查误判、其他内容问题或隐私请求 | {email} |

## 使用问题与建议

使用问题与建议也可以在 QQ 频道「谷地工坊 | 星布谷地种星人聚落」交流，频道号：[{qqFeedbackChannel}]({qqFeedbackChannelUrl})。

GitHub 上的反馈公开可见；不便公开的内容可以通过邮件发送。报告问题时，请说明操作步骤、预期结果和实际情况，并附上应用版本、浏览器和设备信息。截图或能够复现问题的简化示例通常有助于定位问题。

涉及智能体或插画功能时，请注明服务商、模型和错误提示，保留诊断所需的信息即可。发送前请隐去密钥、个人信息和无关内容；可导入图片或存档可能包含完整地图及隐藏标注，请先核对。

## 安全漏洞

请通过邮件私下报告，主题注明 `[SECURITY]`。我们以 72 小时内确认收到完整报告为目标。测试范围、报告内容和协同披露方式见[安全政策](/security)。

## 素材授权与知识产权投诉

请注明 `[IP]`，并提供涉及内容的位置、权利依据或拟使用方式，以及便于回复的联系方式。投诉时，请说明具体问题，并确认所提供的信息真实、准确。

我们会核查属于项目控制范围的内容，必要时请您补充材料，并告知处理结果。涉及用户在其他平台发布的作品时，请同时联系该平台；本工具无法直接撤回外部副本。

## 内容检查反馈

如果检查影响了正常导出，请说明出现问题的字段或功能、应用版本和大致操作步骤。您可以自行决定是否提供相关文字或图片；请只发送定位问题所需的最少内容。

本机检查不会自动向团队发送原文或地图。反馈会用于处理您提出的问题，发送反馈本身不表示同意将材料用于模型训练。

## 隐私请求
