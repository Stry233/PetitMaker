# 关于 {app}

{app} 是一款面向游戏《星布谷地》的**非官方**同人地图规划工具。它并非由游戏发行商制作或运营，仅代表其自己的小型团队发声。

## 使命

{app} 让你在浏览器中规划地图，在与游戏相同的格子上布置地形、水域、道路与物件，使你可以先在这里完成布局，再在游戏中放心还原。你在这里设计的每一张地图，都力求能在《星布谷地》游戏中 100% 复现。

{app} 最初只是一群玩家出于自身需要而发起的小型志愿项目：他们希望在游戏中动手之前，有一种更快、更从容的方式来规划建造。它由这一需要生长而来，而非出于任何商业目的。它始终是玩家在业余时间制作的非商业同人项目。

## 技术

{app} 是一款浏览器应用，使用 TypeScript、React、PixiJS（用于 2D 编辑器）与 three.js（用于 3D 预览）构建。

**它如何运作。**本工具完全运行于你的浏览器中：它是一个**没有后端、也没有用户账户**的静态单页面应用。你的地图保存在本地，即保存在浏览器存储以及你自行导出的文件中，**不会存储在我们的服务器上**。这里没有任何需要注册的东西，我们也不持有你作品的任何集中副本。可选的 AI 智能体基于你自行提供的 API 密钥运行，请求会从你的浏览器直接发往你所选择的提供商；相关数据的流向载于[隐私政策](/privacy)。
