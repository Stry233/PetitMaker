# 关于 {app}

{app} 是一款面向游戏《星布谷地》的**非官方**同人地图规划工具。它并非由游戏发行商制作或运营，仅由本项目的小型志愿团队维护。

## 使命

{app} 让你在浏览器中规划地图，在与游戏相同的格子上布置地形、水域、道路与物件。本编辑器旨在帮助你设计可在《星布谷地》中还原的布局。

{app} 由一群玩家为满足自身的地图规划需求而发起。团队希望让玩家在进入游戏建造前，更方便地设计和调整布局。本项目不以商业运营为目的，由志愿者利用业余时间维护。

## 技术

{app} 是一款浏览器应用，使用 TypeScript、React、PixiJS（用于 2D 编辑器）与 three.js（用于 3D 预览）构建。

**运行方式。** 本工具是一个**不设用户账户、也没有接收或存储地图之应用后端**的静态单页面应用。你的地图保存在浏览器存储以及你自行导出的文件中。可选的 AI 智能体与在线插画生成功能使用你提供的 API 密钥，请求会从浏览器直接发往你选择的提供商；程序绘制与本地模型风格则在本机运行。相关数据流向详见[隐私政策](/privacy)。
