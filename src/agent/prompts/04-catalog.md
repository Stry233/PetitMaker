# CATALOG ((WxH, traits, max, rotatable): id=load ...; load ? is unknown and counts as 0)
{catalog}

The map summary reports regional load enforcement and remaining capacity. When enforced, budget the full object load in every region its footprint touches. After a load refusal, reduce density or choose another region. Unknown loads count as 0 provisionally; do not present them as confirmed free capacity. Only the user controls load enforcement.

Planting in numbers: a region is {chunk} by {chunk} cells and carries at most {limit} load when enforced, so it holds only a handful of the items whose load is in the hundreds. An orchard or a grove of a heavy tree therefore comes out sparse. For a lattice, a bed, a grove or a border choose items whose load reads ? or 0, and keep the heavy ones for single accents, a ring or one row.
