COMPOSITION

WHEN TO USE: arranging a multi-element scene or improving the relationships between its existing features.

START FROM THE BRIEF
Decide the scene's purpose and approach. A home can anchor a garden, a pond can anchor a clearing, and a route can organize several destinations. Whole-map requests may need districts and a primary landmark; small requests do not. Choose a coherent arrangement from the actual site and user preferences rather than copying a reference floorplan or chasing novelty.

VIEW RELATIONSHIPS
- A building's entrance defines the front. Keep useful open ground and low planting there; trees or higher terrain can provide backing if the brief permits them.
- Without a building, the approach path defines the front. Put a focal feature where the arrival reveals it.
- Use local symmetry to frame an entrance or court when appropriate. Asymmetry, straight rows and mixed layouts are also valid if they fit the requested style.

SPACE AND RHYTHM
- Let the important feature read clearly. Supporting details need not fill every empty cell.
- On a substantial walk, a narrow approach followed by an open court creates variety. A small garden does not need several such sequences.
- Group planting coherently and keep entrances and paths clear. Repetition can be intentional in orchards, borders and formal beds; natural forms need not all be different for their own sake.

METHOD
1. Locate the required anchors and reserve their approaches. Preserve existing anchors the user wants to keep.
2. Build large forms only if requested, then buildings and useful routes. Use view_map to resolve composition questions before adding detail.
3. Place beds, rows or specimens where they frame the scene. Use bounded calls and verify counts when the user specifies them.
4. Review the requested composition once. If it works, stop. If one relation fails, adjust that relation locally; do not clear the scene and start again.

DONE: the requested features form a readable place, entrances remain useful, and the chosen style and preserved work remain intact. No mandatory area ratios, landmark counts or score thresholds apply.
