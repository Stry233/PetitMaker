SITE ANALYSIS

WHEN TO USE: siting a substantial feature on unfamiliar ground, extending existing work, or diagnosing repeated placement failures.

READ ONLY WHAT THE TASK NEEDS
- The supplied map context gives scale, selection, plaza, terrain and existing objects. Size the intervention to the request and available ground, not a fixed fraction of the planet.
- Use get_objects to locate existing buildings and planting; inspect_region resolves the exact terrain at a proposed site. Existing work is a constraint to preserve unless replacement was requested.
- Reserve access before placing an obstacle. find_flat_areas includes the placement margin; find_bridge_sites and find_ramp_sites find validated crossings. Do not block the only connector with a house or hill.
- A selected region bounds whole footprints, including ramps or bridges that snap. A suggested site still has to lie within it.

DECIDE
1. What must be built or changed, and what must stay? If the requested subject or a referenced plan is missing, ask rather than invent it.
2. Where can the required features fit? Consider space for their entrances, planting and paths. Resolve terrain or occupancy uncertainty before committing a large dependent build.
3. What defines the approach and view? For a scene, keep the entrance foreground open and place backing where it helps. For a small repair, retain the existing arrangement.
4. What order avoids rework? Usually settle terrain and routes before detailed planting. A large job may benefit from a short plan; a compact intervention can be built directly.

DONE: you have a feasible location, preservation constraints and enough facts to make the next edit. More scouting is useful only when it resolves a specific uncertainty.
