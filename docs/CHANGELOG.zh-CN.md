# 更新日志

谷地工坊的重要改动都记录在这里。

本文件的格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号力求遵循[语义化版本](https://semver.org/lang/zh-CN/)。

## [0.6.28] - 2026-08-11

### 新增

- **用一个字母、一张图片生成岛屿。**生成栏新增"字母"与"图片"：输入一个字符或提供一张图片，就能把它的形状建成岛屿，连每个边角的修剪都取自原图轮廓。图形落地前可以在区域内拖动调整位置；放不下时会明确说明，而不是溢出区域。
- **画好的区域可以整体拿起搬动**；在 3D 视图中，区域会贴合其下方的地形起伏。

### 修复

- **瀑布不再允许修剪边角。**下落的水面整体锁定，任何高度都剪不出缺口。
- **放置虚影在悬崖前也看得清。**3D 视图中的虚影改为黄色，不会再隐没在坡面的绿色里。

## [0.5.550] - 2026-08-11

### 新增

- **新增智能建造栏，一次按下即可建成一整处景观。**先选择要建的内容，再在地图上按下：阶地小山、一路下行汇入水体的溪流、道路，或一片种植。每种在落地前都会预览将建成的样子，按住不放则会继续生长。种植会读取其周边环境，因此建筑旁会出现花坛、道路旁会出现绿化带，按住不放还可让植群逐步成熟。
- **道路可按指定路线铺设。**先按一点、再按另一点即可连通两处，工具栏会给出找到的若干走法及各自的代价。再次按下会给出同一座岛的另一种布局，而不是在原有布局上叠加。整岛按下则会铺出路网，并把街道终止于各家门口。
- **迷宫可指定入口与出口。**打开标记开关并拖动到所需位置，全部候选方案都会依此生成；两点之间的路线可以显示出来，并以真实道路铺就。
- **橡皮擦支持矩形与圆形擦除**，原有的点擦保持不变。在一角按下、拖出形状，松手时整块一并擦除；按住 Shift 可得到正方形或正圆。整次擦除记为一步撤销。
- **恢复上次进度时一并恢复可撤销的操作**，最多保留最近 60 步，与地图和视角一起恢复。
- **坡道与桥梁可落在半格网格上**，因此跨越结构会正好落在缺口处，而不是偏开一格。
- **物品栏的搜索更宽容。**支持一次输入两个词，容许拼写错误，并可通过别名或颜色找到物品。
- **生成面板提供可直接查看的候选方案。**每张卡片都是该配方所生成地图的照片，点击即为确认，无需二次操作。

### 变更

- **全新界面，采用游戏本身的风格。**工具改为顶部的五个模式块，选中哪个便显示对应的工具栏；图层与视图控件位于右侧一列；各窗口统一从菜单进入。整体按笔记本屏幕排布，屏幕较小时会整体缩小，而不是遮挡地图。
- **新的默认键位，与游戏操作对齐。**地形工具按工具栏顺序排布在数字键上，WASD 平移地图。所有命令仍可重新绑定，原有键位作为预设保留。
- **保存与分享合并为一个窗口**，分为三部分：继续编辑、分享图片、查看建造清单。
- **3D 视图以正视角打开**，与 2D 视图一致，并且打开更快：在使用 2D 视图期间即在后台预取其场景。开场镜头动画过程中操作镜头会立即落到最终视角，而不是等动画播完才响应。
- **满地图编辑更流畅**，在存在大量选中物件时尤为明显。每笔背后的承重检查开销降至原先的约五分之一，3D 水面动画也改由显卡计算，不再逐帧重算。
- **框选区域在 3D 中更清晰**，改用白色绘制，不再是绿底上的绿色。

### 修复

- **笔刷预览与实际落笔一致。**预览贴合所悬停的表面，磨圆该笔真正会磨圆的边角，并将待放置物件绘制为一个整体而非多个部件的堆叠。
- **水会顺着所经过的地面走**，除非手动锁定了图层。
- **山体与水体相接处的切角会朝向该山体**，使交界读作一条连续的线；两处岸线在一点相接时也会正确焊合。
- **含半格跨越结构的存档在导入时不再丢失撤销历史。**
- **生成面板的配方输入框改为一条书写线。**空白处位置与长度不随数字增长而改变，光标高度与相邻数字一致。
- **道路的圆角在生成或智能建造之后可能保留旧形状**，直到附近其它内容被重绘。
- **生成器运行失败不再导致后续生成全部退回主线程**，此前会使该次会话中之后每次操作都变慢。
- **数字快捷键按物理按键触发**，不受键盘布局输出字符的影响。
- **光标反映的是当前所用工具**，而不是刚刚离开的那个。

## [0.4.149] - 2026-08-02

### 新增

- **首次打开编辑器时提供新手引导。**内容包括移动地图、菜单的位置、查看方块位于第几层，以及 2D 与 3D 视图之间的切换。可随时跳过，也可在设置的“新手引导”中重新打开。
- **曲线工具改为通过所设的锚点。**单击添加锚点，拖动可调整其位置，双击结束绘制。绘制完成后锚点保留，每个锚点两侧各有一个手柄用于调整弧度，按住 Alt 可只调整一侧。每次调整记为一步撤销，按 Esc 收起手柄。
- **笔刷预览显示自动修边之后的形状。**开启自动修边时，预览中磨圆的边角即为该笔最终会磨圆的边角，矩形、圆形、直线、曲线均是如此；自由笔刷在绘制过程中即时修边。
- **新增 19 种花卉配色**，可摆放物品增至 81 种。
- **重新绘制了鼠标指针。**指针会指示当前位置点击后的结果：不可摆放处显示禁止标记，可拾取处为张开的手，拖动中为握合的手，可转动 3D 视角处为旋转箭头。
- **两种导出均提供快捷键。**Ctrl+S 保存 JSON，Ctrl+P 导出分享图，新建地图为 Ctrl+Alt+N（Ctrl+N 由浏览器占用）。快捷键页面可查看并改绑 Alt 组合键，与 Ctrl、Shift 相同；按 m 显示或隐藏菜单。
- **新建地图前，若当前地图尚未导出会先行提示。**
- **2D 视图中的桥与坡道显示朝向。**桥的图标随桥体一同旋转，坡道的图标由低端指向高端。
- **3D 视角具有惯性滑动**，两个 3D 界面共用同一套按键平移，并提供两档速度：连按两次方向键为较快一档，按住 Shift 为较慢一档。
- **适配手机屏幕**；在其他应用的内置浏览器中打开时会给出提示（部分功能在该环境下不可用），界面标注 Beta。
- **AI 智能体的改动限制在已绘制的选区之内**，与生成器一致。
- **更新日志与素材许可提供中文版本**，应用内与仓库中均可查阅。

### 变更

- **分享图采用新的编码格式**，携带的数据更少，读出的仍是同一张地图。图中的编码称为 PetitGlyph，位置移至页边，同一张地图的编码也更短。此前版本导出的图片不再支持导入，如需继续分享请重新导出。JSON 存档不受影响。
- **“清除”改为撤销上一次生成，不再清空整张地图。**其范围限于该次生成所使用的选区，手动摆放的内容予以保留。
- **道路上不可摆放物品。**在已铺设道路的格子上摆放物品时，会移除该处的道路，与游戏规则一致。
- **浏览器缩放不再影响 2D 地图。**缩放页面不会改变地图的大小与位置，之后拖动地图也不会发生跳变。

### 修复

- **自动修边可能在刚绘制的地形中留下一个空格子**，并在之后报告悬空方块的错误。
- **图形跨越不可建造的地面时，整笔都无法绘制。**现矩形、圆形、直线与曲线会绘制其中允许的部分，跳过其余部分。
- **笔刷预览可能修改其所预览的地图**，导致已有方块被删除。
- **在某一选区内生成，会清除此前在另一选区中摆放的物品**，且新生成的区域可能显示为空。
- **图层锁定后，笔刷拖动经过时，图层面板中的图标持续闪烁。**
- **调整窗口大小时，生成面板的模式按钮会发生位移。**
- **应用加载完成之前，页面标题同时显示中英文。**
- **点击广场时会说明拒绝的原因**，此前没有任何反馈。
- **导入早于某次物品新增的分享图失败时，会说明失败的原因。**
- **修饰键提示在按下按键时即显示**，不再等待下一次移动指针。
- **在 2D 视图中使用拖拽工具拖动地图**时，地图可能滑出很远，而不是跟随指针。
- **摆放前使用逗号与句号键旋转物品**时，预览会立即更新，不再等待下一次移动鼠标。
- **横屏提示改用可识别为旋转的图标。**

## [0.1.1645] - 2026-07-30

谷地工坊是一个在浏览器里运行的《星布谷地》地图规划工具。先在这里规划一座岛，再到游戏里照着搭。所有数据都不上传，也不需要账号。

### 新增

- **同一张地图，两个编辑视图。**2D 和 3D 编辑的是同一张网格，每件工具在两边都能用。编辑到一半切换视图，地图、选中项和历史记录都保持不变。3D 视图另有水面动画、柔和阴影，每件摆放的物品都有对应的模型。
- **地形笔刷自带规则检查。**自由笔刷、直线、曲线、矩形、圆形，另有笔刷大小调节。画出游戏里不允许的结果，这一笔会当场撤销，编辑器会说明是哪条规则没通过。
- **物品在落地之前就检查。**放不下的位置会被直接拒绝，而不是先放下再收回。桥在两岸平整且高度相同时会自动对齐就位。
- **62 件可摆放物品**：小屋、设施、桥梁、坡道、树木与花草，另有两种道路，像笔刷一样直接画。物品吸附网格，点击旋转，拖动换位置。
- **边角切割。**可以一次修一个山角，也可以打开自动修边，边画边修，形状在切角和圆角之间选择。
- **八个图层**，每层都有独立的显示与锁定开关；橡皮每次削掉一层。
- **两种生成器，同一个配方号。**随机会设计一座有人住的岛：主题各异的街区、能走上去的台地、逐级流入海里的河道、两岸等高处的桥，以及连到每一户的道路。迷宫则把可建造的地面铺成通道。同一个号码永远生成同一张地图，所以喜欢哪个号码，直接发给别人就行。
- **自然度滑杆**，同一个配方可以从方正一路调到自然，另有最大高度限制。
- **分享图就是地图本身。**地图可以导出成一张图片，上面带有可见的 PetitGlyph 色带。把这张图片放回编辑器，就能一格不差地还原出这座岛。导入时会先校验，图片损坏到读不出来时会明确告知。
- **JSON 存档与读取**、可分节导出的 JSON，以及能把旧存档升级到当前版本的存档格式。
- **自动保存**在你自己的浏览器里，下次回来时会询问是否恢复。
- **可选的 AI 智能体。**密钥用你自己的，加密保存在你的设备上，支持九家服务商，也包括任何 OpenAI 兼容接口。它先写出方案，走的是和你的画笔同一套规则，每个阶段都留成一个可以回退的节点。它动手之前问得多勤，由你决定。
- **可交互的快捷键页面。**所有命令都画在一张键盘上，含修饰键分层和小键盘。点一个键就能看到它的作用，录一组新的组合键即可改绑，也可以搜索还没有绑定按键的命令。绑定会保存下来，并支持导出和导入 JSON。
- **七种界面语言**：中文、英语、日语、俄语、泰语、印尼语和法语。
