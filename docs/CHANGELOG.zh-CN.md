# 更新日志

谷地工坊的重要改动都记录在这里。

本文件的格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号力求遵循[语义化版本](https://semver.org/lang/zh-CN/)。

## [0.10.36] - 2026-09-11

### 新增

- 项目主页和「关于」新增 Patreon 和爱发电赞助入口。

### 调整

- 「关于」将团队信息置于首位，赞助入口放在法律文档下方，GitHub 链接放在版本信息下方，并移除图形渲染信息。
- 山体智能建造可喷绘局部山丘，原地按住逐步增高，拖动沿轨迹延伸山脊，整次操作可一次撤销。道路连接指定端点或建筑入口，会在路线更合适时搭建合法的桥梁和坡道，并对齐通行结构两端的道路。河流可连接池塘、形成瀑布，并通过控制点调整弯曲。预览包含支撑地形和通行结构，每次调整都可单独撤销。每种地表的智能建造按钮直接启用唯一操作；道路工具条移除「全部连通」。
- 图片生成的最小选区从 20×20 降为 7×7 格，并优化较小选区的细节采样。宽高均不少于 20 格时，生成效果保持一致。
- 生成器的缩略图错误提示统一为简短的范围说明，并在文字上方显示清晰的感叹号标记。区域按钮始终显示选中的格数，不再重复错误提示。
- 规划标注改用固定的十四个标签，不再输入名称。区块带一个标签，文字标注改为标签牌。早期版本的存档和分享图片打开后，区块不带标签，文字标注不再保留。
- 区块可以分多笔画出：笔画先汇入草稿，点击「完成」后生效；从已有区块内部开始的笔画会扩大该区块，擦除工具会去掉格子，笔刷仍处于选中状态时在区块内部单击即可选中区块。
- 动线可以一笔拖出并保留可调节的锚点；在已有动线附近按下即可选中它。

### 修复

- 可以从悬浮工具条和颜色列表的阴影、间隙处开始绘制地图，按钮和滑块仍可正常操作。
- 界面放大或窗口变窄时，角落按钮会自动错开，底部按钮会优先调整排列，为展开的图层面板保留右侧空间。撤销和重做始终靠右对齐，滚动列表只为同一高度的按钮留出空间。界面会根据可用空间调整实际显示大小，同时保留已保存的缩放偏好。
- 笔刷滑块与工具行垂直对齐，悬停时的数值提示不再被裁切。图片生成器的滑轨长度与其他生成器一致。
- 界面会根据文字实际显示大小、屏幕像素密度和文字类型，适当调整小字号文字的字重，同时保留常规文字和标题的层次。
- 调整窗口或界面缩放后，助手角色会跟随新位置，不再停留在上一次的位置和大小。
- 文字生成更好地保留分离的笔画、附加符号和字内留白，减少小选区中笔画交汇处不必要的堆叠。
- 在 2D 和 3D 视图中，地形绘制和擦除现在准确作用于指针下的方块，预览与实际修改位置保持一致。
- 智能体的修改被部分撤销时，现在会说明地图上保留了哪些修改，并将其计入修改数量。
- 智能体在等待批准或两次修改之间收到停止、暂停操作时，会及时响应。已取消的输出不会覆盖新会话；上下文无法继续压缩时，会显示错误并结束任务，避免重复请求。
- 保存的智能体事件数据损坏时，现在会进入现有的数据恢复流程，避免会话恢复失败。
- 打开帮助时不再提前生成或截图当前不可见的插图，演示会在窗口入场动画结束后启动。跳转到帮助章节时，会等待目标内容加载后再滚动到对应位置。

## [0.9.334] - 2026-09-04

### 修复

- 文字生成会根据选区的实际宽高调整字体笔画，适应 5×5、5×6 格等小范围选区。字母和数字保留笔画间隙、内部留白和小写特征，大范围文字则保留字体的曲线与比例。复杂汉字会检查笔画是否粘连，表情符号会将内部细节转为留白，中外文字与表情混排时分别适配。输入时按完整字符计数，不会截断组合表情或附加符号，也不会打断中日文输入法组字。
- 在道路较多的地图上使用路面画笔不再卡顿，路面材质的图片方案预览生成也更快：此前每一笔都会把整片相连路面的边缘渐隐重新计算十余次。
- 庭园石路、公园石路和简约花圃路上现在可以种植花草，与游戏中的可种植路面一致。
- 「键盘快捷键」窗口宽度不足以显示整块键盘时，键盘下方现在有滚动条可以拖动；此前只能用滚轮或触控板滑动，没有可见的把手。
- 物品架的分类名称超出可用宽度需要横向滚动时，选中靠后的分类不再使分类行跳回开头，所选分类保持在可见范围内。
- 修复多个会冲掉创作记录（AI/人工来源标记）的操作：更换星球时创作记录会随建筑一并迁移；移动或旋转物件时保留原作者，不再记到拖动者名下；重绘内容完全相同的格子不再改写作者；从分享图片导入时保留图中记录的 AI/生成标记；读取存档时会校验并核对创作记录与实际载入的内容。

### 变更

- 国际站点迁至 [petitmaker.cc](https://petitmaker.cc/)。页面标题和搜索信息使用各站点对应的语言，并更新规范网址与站点地图。

- 可导入分享图中的 PetitGlyph 改为更矮的固定高度色带，采用四种草绿色阶，码内不含文字。新的纠错方式提高了图片缩小和重复压缩后的读取成功率。对于内容特别密集的地图，导出时会建议分享原始文件。第 1、2 版分享图片仍可读取。
- 生成岛屿的规划速度提升，在性能较弱的设备上更为明显；相同种子生成的结果不变。
- 切换回已有预览的生成类型时，会立即恢复候选卡片，无需重新生成；手动输入的配方号也会恢复，程序、文字和图片生成均适用。
- 每种生成类型分别保存候选卡片与配方号。为一种类型生成新一批候选卡片，不会改变其他类型的内容。
- 铺路时只重新计算笔刷所在的路面，不再重算地图上的全部路面，道路较多的地图上铺路更流畅。
- 启动画面的标识改为跟随站点域名，与加载页保持一致：国际站始终使用英文标识，大陆站始终使用中文标识，不再随语言设置在启动过程中切换。
- 「设置」底部新增键盘快捷键预览，每个按键按照功能类别着色，修改绑定后会同步更新。点击预览即可打开「键盘快捷键」窗口。
- 「撤销」「重做」和两个界面缩放命令现在都可以在「键盘快捷键」中重新绑定，也可以将原按键分配给其他功能。界面缩放快捷键在对话框打开时仍然有效；与其当前按键对应的 Shift 组合会保留，因为它们使用同一个物理按键。
- 2D 地图中滚动改为缩放，以指针位置为中心，与 3D 视图一致：鼠标滚轮一格为一级缩放，触控板滑动和双指开合为平滑缩放，横向滚动同样缩放。平移使用拖动（右键或中键、空格加拖动）和键盘平移键。
- 导出普通图片时，如果没有勾选任何附加内容，将只保存地图本身，不再带卡片边框；关闭分层预览时，地图会占满卡片宽度，不再留有大片左右空白。每张导出图片底部新增制作栏和应用标识。

### 新增

- 目录加入游戏新增的三种路面：玉米金砖路、翻耕土路、乡村土路。旧存档和分享码里已停用的纯色土路，现在读取为游戏中的乡村土路。
- 内置帮助中心，入口在菜单的「帮助」：涵盖上手、视角、各建造工具、生成、规划、保存与分享、智能体和设置，并覆盖应用支持的全部语言。帮助中的动画演示直接在真实星球的一块区域上运行编辑器，界面配图也使用真实控件。每页都带有问答，搜索框可同时检索页面和问题；帮助窗口标题栏的问号可切换成「这是什么」模式，点击界面上任意控件即可打开对应说明页。
- 规划标注图层：可在地图上圈画带名称和编号的区块、放置文字（地图字样或彩色底板）、绘制动线箭头。动线画完后锚点仍可调整，操作方式与地形曲线画笔一致，也带方向控制柄。点击区块标签即可选中区块，按住 Ctrl 点选或框选可多选，Ctrl+A 全选，选中的多个标注可一起移动、改色或删除，多个区块还可合并为一个。所有标注都在独立图层上，图层面板中可显示、隐藏和锁定；2D 和 3D 视图中都会显示，3D 中贴合地形起伏；随地图存档和可导入的 PetitGlyph 一起保存，导出时可另行选择是否在图片中显示。
- 导出 2D 分享图时可选择画风，将地图重绘为插画。内置的程序画风与本地模型画风都在设备上运行，不需要 API 密钥，也不会发出网络请求。在线预设画风与自定义描述使用当前服务商菜单中选定的图像服务，并由你自行提供密钥。无论模型在本地还是在线运行，只要图片由模型生成，角落都会标注由 AI 绘制；纯程序绘制的图片不带这项标记。全部画风在同一列表中显示，并标注预计耗时；同一次导出可以生成多个方案，与原图比较后再选择导出。再次使用内置画风会得到略有变化的新方案，而不是重复同一张图。

## [0.8.39] - 2026-08-27

### 变更

- **分享图会等你输入完再刷新。**在分享窗口编辑标题或描述时，预览图此前每次内容变化都会重绘，使用输入法时相当于每敲一个键都刷新一次。现在会等文字停止变化一秒后再更新一次，为新标题重建还原条时也不再闪回加载动画。

- **物品栏会记住你的选择。**此前切到其他模式去雕地形或铺水后，物品栏会重置回第一个分类。现在切回来时会停在之前所在的分类，之前选中的物品仍处于选中状态，可以直接继续摆放。

### 修复

- **坡道在山体四周的放置手感一致。**此前边缘检测偏向右侧和下侧：坡道能贴着崖边的右端放置，左端却放不上；从南、东两侧指向台地时的可放范围也比北、西两侧更深。现在四个朝向、两端的可放位置完全一致。

- **Safari 中的描边与其他浏览器一致。** 圆形按钮、名称标签和各类绘制控件上的细描边，此前在 Safari 中显示得偏粗偏虚，名称标签展开或收起时还可能在地图上残留碎片。现在描边清晰锐利，也不再留下残迹。

- **所有读屏标签都跟随界面语言。** 此前有两处标签无论语言如何都固定为英文：导出帮助气泡的按钮和曲线工具的可拖拽控制点。现在两者都与界面一同翻译。

- **动画设置里的风车绕自己的圆心旋转。** 设置中的风车此前绕着轴心下方一点转动，看起来在晃而不是在转；现在严格绕轴心旋转。

## [0.7.781] - 2026-08-26

### 新增

- **全新的助手面板。** 助手不再是一个聊天窗口，而是地图旁常驻的一列。桌面上有一张卡片说明当前状态：等待指令、思考、施工、暂停或已停止；下方的记录是一份纸面档案，包含你下的指令、可逐阶段确认的计划、每一步及其结果，任务结束后还有一张回执。某一步被游戏规则拒绝时，会用你的界面语言写明原因，并在句首标出规则所属的类别。回执可以翻面，查看这次建了什么、撤回会收回哪些内容。没有填入密钥时，面板处于休息状态：助手在桌前打盹，卡片上带有测试版标记，旁边的板子列出她能承接的几类工作，只留一个「连接」按钮通往设置表单。收尾之前，助手会把成果对照你指令的原话检查一遍，把没做到位的地方补齐；她的建造知识整理自资深玩家的成品地图，因此布局遵循玩家的实际建法。
- **助手面板可以停靠在窗口左侧或右侧。** 面板上角的圆形按钮可将它停靠到窗口一侧，占满整个高度；编辑器的其余部分随之让开，并按同一比例缩放到剩下的空间里：模式栏、底部栏、角落控件和各个面板一起变小，而不是被面板盖住。停靠后，这个按钮和它下方的第二个按钮固定在面板右上角，无论面板靠在窗口哪一侧，位置都相同；只有旁边的状态卡片为按钮让出位置，下方的全部内容都铺满面板宽度，未连接时的示例订单全部列出，空闲时的草图卡片就落在输入框旁。第二个按钮可把面板移到另一侧，整个界面随之换边。原先让给底部栏的高度，现在归记录使用。这两项选择都会被记住：上次停靠在右侧退出，下次按下助手时仍停靠在右侧。若窗口宽度不足以同时容纳界面与面板，面板会自动恢复浮动并给出提示，窗口变宽后再自动停靠；在此期间按钮保持可见，并说明原因。
- **停靠的过程是界面让开、露出下面的面板。** 浮动面板会和助手一起收起，随后编辑器的其余部分才滑开，把面板作为它一直立在其上的底面带到眼前。面板并非静止不动，而是随着界面的离开一并滑入，两者像两层纸一样先后错开、最后齐平。取消停靠时顺序相反：界面先盖回面板，浮动面板再从助手所在的那一角重新展开，助手也一同回来。把停靠换到另一侧是一次连贯的横穿，而不是两段滑动：界面从面板上方一次掠过，中途不停，面板则在被完全遮住时换到另一端。
- **整个过程中地图始终不动。** 无论平面视图还是 3D 视图，界面让开与盖回时小岛都停在屏幕上原来的位置，因此地图切换到新宽度的那一刻不会突然跳一下。
- **监督的严格程度由你决定。** 每次改动前都问、只在大范围改动前问，或者放手让它做。提问会作为一张卡片留在记录里，连带它所针对的计划或调用；不按「同意」而直接回话，则这句话会作为指引发出，同时取消那次调用。连续答复过的提问会在原位叠成一小摞，露出数量和最新的答复；按一下展开，再按一下收起，尚待回答的提问始终保留完整卡片。
- **每一种撤回都放在对应的工作旁边。** 已结束的任务可以整单撤回，计划中的每一步也可以单独回退，每次都先确认，并说明会从地图上收回多少步、其中有多少是你自己的改动。在另一张地图上完成的任务不提供撤回，并会说明原因。
- **施工过程中可以随时补充要求。** 任务进行中发送消息，会作为下一步的指引排队，而不是另起一个任务；排队中的留言在发出前可以撤回。停止会先在卡片上确认一次，已停止的任务保留此前建好的部分。
- **九家平台，另加任何兼容 OpenAI 的接口。** 设置界面接收密钥后会判断它属于哪家平台，停笔片刻便自动校验，模型一栏写明这次连接将使用的模型。无法判断的密钥会给出选择列表，而不是替你猜。自定义接口可以指向任何兼容的服务器，包括本机上的。
- **等待时，助手会在你的岛上画草图。** 空闲时面板会在当前地图的照片上蒙一层描图纸，一次画一个提议：给还没有路的地方画一条小路、在洼地画一片水塘、在裸坡上画一丛树。按下它会把这条提议填进输入框，可以直接发送也可以再改，面板本身不会替你发出。
- **指令可以写多长就写多长。** 助手的输入框会随着输入逐行变高，最多四行，之后在框内滚动。文字超过四行时，旁边会出现一个按钮，把同一个输入框展开成一张浮动卡片，足够写下并通读整段内容；收起卡片后输入框回到原位，写好的文字一字不少。文字装得下时不会出现这个按钮，卡片和输入框也不会同时出现：始终是同一个输入框，只是按指令的长短换个大小。
- **设置面板更直观了。** 所有选项集中在一块面板上，多数设置直接展示效果：网格和画质选项是几张小地图，拖动界面大小滑杆时旁边的示例文字会跟着缩放，动效选项各自演示自己的样子。语言一栏直接列出各语言的本名。
- **动效、网格线和区块边界的设置现在会保存，下次打开保持不变。**

- **新手引导补上了 3D 视图，并把每个操作画出来。** 引导过程中会切换到 3D 视图，说明在其中如何移动视角（按住右键或中键拖动旋转小岛，按住左键拖动平移视角，滚轮拉近推远），并说明所有工具在 3D 表面同样可用，最后再切回平面视图。凡是讲解操作手法的步骤，现在都配有一幅小地图来演示：指针、它按住的那一个鼠标键、它拖出的轨迹，以及地图随之平移、旋转、拉近或被笔刷画上一道。任意键都可用的步骤会一次演示一个键，每次都是完整的一遍动作，不会让人误以为要同时按下三个键；滚轮则画成正在滚动的滚轮，而不是被按住的样子。在「减弱动态效果」下，每幅小图停在动作完成时的状态，轨迹已经画完，按住的那一键仍是亮的，因此说明本身不依赖循环动画。
- **图片可以用路面来铺，也可以只用花或只用树。** 图片选择材料的那一行提供山体、水面、混合之外的「路面」，按颜色匹配游戏中的路面，铺成一片带图案的平地。也可以限定为只用花草或只用树木：游戏里树比花高出许多，两者混在一张图上会显得杂乱。即使图片逐格铺满，铺路也很快：160 格宽的图片零点几秒内就能铺完。
- **「混合」是一种构图，而不是一套配色。** 混合材料先用地形铺出画面的底子，山体与水面兼用，画面中真正偏蓝的区域会成为一片真实的水域；随后在承载画面的位置摆上花草：变化最剧烈之处，以及颜色离绿色色阶最远之处。其中不含树木，因为游戏里树比花高出许多；想用树的图片请直接选择「树木」。
- **「生成」现在会规划出一座岛。** 三种岛屿类型改用新的生成器，其建造方式与玩家一致：先在广场四周安排各个场所，为每处定下朝向并在其身后立起山体，再以主次分明的道路把它们串起来（通往建筑的街道更宽，其余更窄，且不留断头路），把镇子所在的地面修成台地，并让每处场所使用同一套配色。图鉴中的每座建筑与设施都恰好出现一次，这是旧生成器未能做到的。
- **「自然度」改为「丰富度」。** 这根滑杆的含义与它一直以来调节的一致：这座岛有多丰富。调低可得到一座平坦的花园小镇，街道两旁排布花圃；调高则是层层台地的岛屿，每一层都有水面，还有果园，以及写在远处山墙上的景观图案。陆地、水域、混合三种类型仍与其名称相符：陆地完全没有水面，水域则让更多面积成为水。
- **抵达提示会说明你当前身处哪颗星球。** 打开岛屿时，屏幕上方会出现一条小提示，显示星球的图片与名称：启动时、恢复已保存的进度后（并补充说明进度已恢复），以及切换星球之后（并说明这次迁移的损失）。提示在几秒后自动消失，不会遮挡错误提示，会等新手引导结束后再出现，并带有「切换星球」按钮，可直接打开星球选择。
- **开屏加载页，预先备好全部美术素材。** 每个版本首次访问时，一座小岛会随图标、光标、界面图形和字体的下载逐格搭建，进度按钮显示真实进度；完成后加载页向上滑出，编辑器随之滑入就位。之后的访问会跳过加载页，且跳过与浏览器的真实缓存核对：强制刷新或缓存被清空后，加载页会重新出现，因为素材确实需要重新下载。程序代码本身下载期间，页面显示应用自己的米色底面和轻微脉动的圆点，而不是白屏。
- **3D 画质设置。** 设置页新增 3D 视图画质选项：自动、完整、精简。自动保持原有的自动判断：没有可用图形加速的机器使用较轻的画面。完整与精简则固定选择，适用于自动判断失误的机器，或愿意忍受较慢的完整画质来截图的场合。
- **「关于」中会说明当前使用的图形模式。** 关于窗口的版本信息下方新增一行浅色文字，说明浏览器当前是以硬件加速还是软件方式绘制，并显示图形设备的名称。反馈编辑器卡顿时可以直接引用这一行，无需另行查询。
- **新增 25 种游戏内小径路面，带有各自的真实拼贴纹样。** 路面选择栏现已收录游戏内的 25 种小径路面，2D 与 3D 视图均按各自的贴图绘制，不再是单一色块。每个色板直接显示路面本身，鼠标悬停可查看名称。
- **接口不提供所选模型时会明确说明，并直接通往模型设置。** 因模型不存在而被拒绝的请求，此前只会显示一条笼统的出错提示，没有任何可操作的按钮。现在提示中会写出模型名称，唯一的按钮直接打开助手设置中选择模型的位置，而不是提供一次仍会使用同一模型的重试。
- **助手工作期间更换模型、接口地址或服务商时，会说明改动从哪一个任务开始生效。** 正在运行的任务会沿用启动时的连接直到结束，因此中途的改动不会让同一份工作换人接手；界面会给出一条简短提示，说明改动从下一个任务开始生效。改动不会丢失，你下的下一条指令即会采用。
- **更换接口地址时会检查该地址是否提供当前模型。** 若新地址列出了模型清单而其中没有当前所选，助手会改用该地址的第一个模型，并写出两个模型的名称，使这次改动清晰可见、随手即可改选，而不是等到下一条指令时才失败。若地址有响应但未列出任何模型，则保留当前模型，并在该行注明尚未得到确认。接口地址一栏现已移到模型一栏上方，与两者的依赖顺序一致。
- **忙碌指针改为编辑器自己的样式，并且会转动。** 后台有较长的操作在运行时，指针显示本套箭头，肩部有一圈小珠循环转动，不再借用操作系统的等待指针，等待时的画面风格与其余部分保持一致。在减弱动态效果下这圈小珠仍会转动，因为停住的进度标志看起来像程序卡死。

### 变更

- **中国大陆站点以中文标识加载。** 在 petitmaker.com.cn 上，加载页与启动画面无论界面语言都显示中文版标识，与站点自身的标题一致；国际站点仍按界面语言选择。

- **助手在原地展开面板，屏幕上始终只有一个她。** 点击助手时，面板从她身后展开：她仍站在原来的位置，面板由她所在的那个角落展开。面板收起时围在她身外的那个方框已取消，她直接站在岛上；指针停在她身上时她会轻轻抬起一下，表示可以点击。再点一次即可收起面板。
- **助手每次都从收起状态开始。** 面板的展开状态不再跨次保留，编辑器每次打开都停在地图上。会话本身仍会恢复，因此上次留下的未完成任务，在打开她之后仍在原处。
- **助手的连接界面不再显示输入框。** 在索要密钥、走连接流程或停在设置卡片时，用来下达指令的输入框完全不绘制，面板底部站着的是该界面自己的按钮（连接、返回、重试、完成）。此前这些界面下方会留一个无法使用的输入框，邀请用户下达面板并不会接受的指令。
- **全新的指针：大小统一，箭头统一，任何屏幕上都清晰。** 编辑器绘制的每个光标现在都是一个小小的矢量文件：箭头、文字光标和 Ctrl 标记直接由几何绘制，手形、移动十字、旋转弧线和禁止标志以双倍分辨率嵌入其中。浏览器按所在屏幕的像素密度渲染它们，普通屏、高分屏和缩放后的界面上同样清晰；指针在按钮上和在地图上大小一致，用 Ctrl 加减号缩放界面也不会改变它。所有起指向作用的光标统一为一枚黄色箭头，取代原先的蓝、黄、绿三色：当前位置能否落笔，由指针下方的预览格说明，不再靠指针的颜色区分。整套指针也比之前略大一号。
- **生成器只保留一种岛屿，不再分三种。** 陆地、水域、混合本是同一生成器的三种偏好，同时维持三种效果的代价超过了这项选择本身的价值。现在只有「岛屿」一种，按参考地图所描述的风格来建造，海面占多少由「丰富度」滑杆决定，与这座岛有多丰富的其他方面一样。按旧类型保存的地图仍可打开，也仍会照原样重新生成。
- **旧的岛屿生成器已移除。** 现在每座岛屿都由新的生成器建造，被它取代的旧生成器不再保留在程序中。这不影响任何已保存的内容：存档文件与分享码保存的是地图本身，而不是生成它的配方，因此已经建成的岛屿打开后与此前完全一致。按旧生成器记下的配方编号，如今会按当前风格生成一座新的岛屿，而不是它从前生成的那一座。
- **导入的图片按它实际画出的内容来适配，而不是按文件本身的边框。** 在白纸上拍下的贴纸照片，画面大部分是白色，而白色不会生成任何东西：图片只用到了所画区域四分之一左右的面积，其余都花在了始终空着的格子上。现在空白的边缘会被去掉，剩下的部分重新适配，同一张图片因此以约两倍的尺寸呈现，此前糊成一团的细节也能看清。本身已经填满画面的图片保持原样，图片内部也绝不会被裁掉。
- **「最高层」滑杆从「文字」移到了「图片」。** 文字不再需要设定高度，这根滑杆便从该模式中移除。图片的高低本就是它的颜色，因此在图片中它决定色阶的深度。它在每张图片上都与「对比度」并列，当图片改用物件拼贴而非地形上色时则变暗并显示「不适用」，这样切换材料不会让旁边的控件移位。
- **图片的区域重新支持圆形。** 区域界面在图片模式下与文字模式一样，同时提供矩形与圆形：圆形区域内的图片保留中央、舍去四角，属于一种取景方式而非损坏。没有实心内部的图形（涂抹的色块、直线、曲线）仍不提供，因为用它们生成的图片会布满空洞。
- **更小的区域也能生成文字和图片，每张卡片各自判断。** 图片所需的最小区域从 32 格缩小到 20 格，文字从 16 格缩小到 5 格，区域画笔也允许框选这么小的范围。在小区域里，各张卡片不再一起被拒绝：每张卡片会先画出自己的字，能立住就照常提供，因此 E 或 L 在 5 格里就能生成，而 M 或 X 会说明自己需要 8 格才能让笔画分开。连写的字母每字需要 10 格，因为字距会比笔画先消失；汉字每字需要 14 格，一个汉字有六七笔，而一个字母只有三笔。这些都会在生成之前说明，而不是生成之后；整个词一格也放不进去时也会给出提示，不再默默什么都不做。
- **现成图片改用游戏中的邻居头像。** 图片模式的示例改为 14 位邻居的头像，另加应用自己的标志，手边没有图片也能直接试用。头像正是这个模式最擅长的题材：一张大脸配上几种鲜明的颜色，即使只用几百格重建也仍然认得出来，而尺寸偏小的物件图标大多是轮廓，轮廓又是重建时最先丢失的部分。每张卡片显示这位邻居自己的名字，游戏中有中文名的即用中文名。
- **「新建项目」改为「换一颗星球」，岛上的建设可以一并带走。** 菜单中原本用于新建地图的一行改为打开星球选择：当前所在的星球会显示你在上面建了多少，选择另一颗时可以选择把建设带过去，或在那里从零开始。带过去时，全部内容会移到新岛并按游戏规则重新校验，新海岸放不下的部分会被移除，抵达提示会说明移除了多少。切换后无法撤销，重要的地图请先导出。
- **纯色路面已移除，改用游戏中的实际小径。** 土路、石路、红砖路、石板路这四种纯色路面在游戏中并不存在，用它们铺出的地面无法在游戏里照样搭建。现在这四种已移除，路面选择栏只提供 25 种真实的小径路面。已保存的地图、自动存档和分享码在打开时会自动转换：每种旧路面替换为材质和颜色最接近的游戏内路面，布局照旧，并且可以在游戏中搭建。杂草土径是唯一可以种植花草的路面，花坛可以像游戏里那样沿着它延伸。
- **建造工具的预览是画师笔下的格子卡片。** 画笔、橡皮、修边和智能建造此前只显示一块所铺内容颜色的色斑；现在指针带着一张圆角小卡，中央的图形写明正在铺什么，可以落下时为绿色，会被拒绝时为红色。「请旋转设备」的提示也换上了画师绘制的手机翻转图，替代原先代码画的箭头。

### 修复

- **物品栏的模糊搜索从词首开始匹配。** 此前离散匹配可以从单词中间开始，很短的查询会搜出名字里恰好散落着这几个字母的物品；现在每个匹配都必须落在词首。
- **开始使用助手即视为回应恢复提示。** 此前打开助手面板只是把「恢复上次进度」的提示挡住，关上面板它又会出现；现在打开面板就等于谢绝，与选择模式或按下「好」一致。
- **导出分享图在所有机器上都更快。** 编码器现在直接读取绘制完成的画面，不再把每个像素复制出来又写进第二块画布；在没有图形加速的机器上，这一步原本要花好几秒。
- **中国大陆站点的隐私政策如实描述自己的托管方式。**「数据去向」一节此前写的是国际站点的网络，并称来自中国大陆的请求由境外节点处理；petitmaker.com.cn 上现已写明由阿里云边缘网络分发，此类请求通常在境内处理。两个站点的政策各自陈述自己的事实，政策版本升至 1.2。
- **恶意构造的地图文件无法再借机向助手读取的内容里夹带文本。** JSON 导入此前已拒绝物品编号造假的物件，现在还会替换掉不符合应用自身格式的物件 id，堵上手工改动的文件可以藏话的另一个字段。
- **右侧工具按钮在任何窗口下都会报出名字。** 悬停撤销、重做或视图按钮时会展开一块写着按钮名称的小牌；此前窗口较窄或界面放大时小牌不会出现，出现时文字也可能超出牌面。现在任何布局、任何语言下名称都完整落在牌内。
- **调整窗口大小时，地图视野保持原位。** 此前改变浏览器窗口大小，地图是按左上角对齐的，画面内容会向一边偏移，甚至有一半被挤出可见范围，助手面板停靠时尤其明显。现在平面视图与 3D 视图一致：地图区域中央的那一点在缩放不变的前提下仍留在中央。
- **系统指针模式下，地图上的手形平时是张开的。** 在设置中选择系统指针后，macOS 会把平移工具画成始终握紧的手。现在它平时张开，只在拖动画面时握紧。
- **智能建造不会再因一次意外错误而整段失灵。** 此前落笔过程中出现意外错误后，后续每次点击都毫无反应，只能刷新页面；现在会如实报告本次没有建成，下一次点击照常工作。
- **生成不会再因后台线程启动失败而卡住。** 这种情况下候选预览和智能建造会改回主线程完成，不再无限等待。
- **右键现在可以收起画到一半的曲线，** 与收起道路连接标记的方式一致。
- **助手方块不再套用建造模式的选中底衬。** 打开助手后，标记当前建造模式的黄色底衬仍留在她的方块下面，而面板比底衬窄，于是面板顶角旁一直露出底衬的一角，看着像多出一个谁都没有选择的模式。助手是否打开，由立在方块下方的面板本身说明。
- **底部工具栏不再把操作漏给下面的地图。** 此前在路面列表的两块图块之间滚动会缩放地图，在物件栏和生成栏的深色底板上滚动或拖拽也会移动下面的地图。现在这些区域会自己接住操作，地图在真正露出的地方仍可正常平移缩放。
- **水面被拒绝时会说明该用哪一层。** 沿用上一步操作留下的层数去画瀑布，程序拒绝得没错，却帮不上忙：游戏要求瀑布两侧的山体正好达到水面所在的层，而提示里没有一句说水面选低了一层。现在，如果笔触下的地形只有一层能容纳这片水面，提示就会写明是第几层；一层都不行或有好几层都可以时，仍旧显示规则本身的说明，因为列出一串层数并不是答案。绘制本身没有改动：要么按你选的层铺设，要么拒绝，不会把水面挪到你没有指定的地方。
- **字号偏小时，粗体会自动减轻。** 字形一小，最粗的字重就会把笔画之间的空隙填满，于是在 1080p 屏幕上，加粗的文字看起来是一团墨迹，而不是强调。现在文字会按它在屏幕上的实际大小来选择字重：尺寸充裕时保持原样，偏小时由特粗降为粗体，再降为中等。中文和日文减轻得更早，因为相同字号下，一个汉字的笔画数是字母的数倍。
- **在已有地形上向选区内生成，现在可以正常完成。** 在已经建好的岛屿或图案上框出一片选区再生成，此前无论点多少次都毫无变化。原因出在选区边界：选区外的地形要靠选区内的格子支撑，高山需要脚下完整的 3×3 底座，抬升的水面需要两侧堤岸，因此清空选区会让本次生成从未碰过的格子变得不合规，整次生成随即被整体撤回。现在，限定在选区内的生成会先把边界处理好再落到地图上，只归还选区外地形确实需要的那部分地面，其余范围照常建造。在选区内撤回一次生成此前也会这样失败，现已一并修复。
- **无法建造的选区现在会给出说明。** 画在高山深处的选区，是周围地形赖以支撑的地面，那里只能保留周围地形所需的部分，因此在其中点击生成什么也建不出来，看上去与上面那个问题一样。现在这样的一次生成会说明原因，并给出可行的做法：把选区画在较低的地面上，或者扩大选区，把周围的高地一并框进来。如果选区本身可以建造，只是这一次的设计没有在其中安排内容，则和以前一样不作提示。
- **面板和窗口中的文字不再小于周围的界面。** 设置、关于、键盘和导出窗口中，有些文字小到 10 像素，远低于主界面所用的最小字号，于是地图周围的界面清晰可读，立在它上面的窗口却不然。现在面板中的文字一律不低于界面自身的小字号。字号只调大，未改动任何窗口的布局。

- **小尺寸的文字不再变形，笔画该直的地方是直的。** 文字由整格搭成，笔画落在网格的什么位置直接决定它能否留下来：一道横笔如果正好压在两行之间，两行都只有一半覆盖，于是整笔消失，这就是小字缺笔画的原因。现在文字会自动对齐到网格能承载的位置。原先把每一笔削到目标宽度的处理也随之取消：它会削掉让转角成直角的那一格，会在两笔相交处把竖笔整体挪开一格，还会把笔画的两端磨短。现在文字按字体本来的样子建造，直线是直线，斜线是干净的斜坡。

- **「水面」材料现在真的会生成水。** 此前选择水面时，图片几乎全是绿色：那一抹蓝只是八种绿之中的一项，只有本身就偏蓝的区域才会用到它，画面不偏蓝就一点水也没有。现在图片仍以地形立在地上，水面是它内部的材料：画面明亮的部分成为图形内部的水域，轮廓保持陆地，因此每一片水都有岸，图形之外的范围保持原样。单一颜色的图片会成为一片与其形状相同的湖。
- **图片重新使用完整的色阶。** 「最高层」此前由各生成类型共用，而生成栏默认停在迷宫上，迷宫的墙最高只到第 3 层。这个上限被带进了图片模式，因此即使没有动过滑杆，每张图片也只用三种绿色来表现，显得平淡稀疏。现在各类型各自保存这项设置。
- **区域已不合适的卡片会拒绝点击，而不是生成上一次的内容。** 把区域画得太小、不足以生成图片时，卡片会清空并说明原因，但点击空白卡片仍会按上一个区域生成图片。这类卡片现在留在原处并变暗，不再响应点击。
- **区域界面会用文字说明最小尺寸。** 区域短于图片所需时，「完成」按钮显示的是内部名称而不是一句话。现在会说明每边至少需要多少格，七种语言均已补齐。
- **贴着地图边缘也能画出最小尺寸的区域。** 在靠近边缘处拖出图片所允许的最小区域时，图形会朝画面外生长，超出边缘的部分被丢弃：无论怎么拖，得到的区域始终小于逼着它生长的那个最小值。现在它会朝远离边缘的方向生长，因此在地图任何位置（包括四角）都能画出最小尺寸的区域。
- **界面在各种窗口尺寸下都保持同一套比例。** 窗口高度小于整屏时，例如 1080p 显示器上最大化的 Chrome 只留下约 870 像素的页面高度，边框上的方块和按钮仍是原本大小，而各个窗口、提示以及导出面板却随窗口高度一起缩小，文字小到看不清。现在两者依据同一个尺度：只要窗口不小于当初确定版式所用的尺寸，所有元素都按设计大小绘制；窗口更小时，整个界面按同一比例一起缩小。在更高的显示器上，窗口也不再超出该尺寸继续放大，因此编辑器在笔记本和大显示器上观感一致。若希望整体更大或更小，仍可使用设置中的「界面缩放」，或 Ctrl 加减号。
- **文字现在立在它所写的地面上。** 此前文字是按台地堆出来的：轮廓比字身低一层，看上去像每个字都镶了一圈边；而窄到没有内部的笔画根本到不了上面那层，看上去像字被挖出了洞。写在山体上时也会切入山体，而不是立在它上面。现在文字就是立在该区域自身地面上的一层。若某些格子无法立起来，无论是因为跨过了高低差、落在下方地面的边缘，还是所在地面已处于最高层，生成结束后都会说明是哪一种、涉及多少格，而不是让字悄悄缺失。
- **文字的笔画粗细会随区域大小调整。** 此前所有文字无论区域大小都用字体的粗体绘制，而在整格构成的地图上，粗体就是一块板：八格的 M 会把两竖和中间的折笔连成一整块。现在粗细依据每个字符分到的空间以及文字本身的密度来定，仍然过粗的笔画会被削细，因此小区域得到清晰纤细的文字，大区域仍保持有意为之的厚重。区域小到放不下常用字母时，会在生成前直接说明，而不是先建出一团。
- **小区域中的图片能保住形状。** 现在每一格会读取其下方整块图像区域，而不是只取其中一个点，配色匹配也会把无法还原的色差分摊到相邻格子上。细节因此得以保留：在 20 格宽的范围内，一张脸的眼睛不再整个消失。
- **文字所用的物件可以在选定之后更换。** 此前选择「物件」只会在进入时打开一次物件列表，之后既看不到选中的是哪一个，也无法再换。现在设置栏会显示所选物件的名称，点击即可重新打开物件列表。
- **不操作时 3D 视图会保持静止。** 此前水面与瀑布持续播放动画，只要 3D 视图处于打开状态，整张地图就会逐帧重绘。在大型岛屿上，这意味着屏幕毫无变化时处理器和显卡仍在满负荷运转：风扇转个不停、电量快速消耗，平移和编辑也要与之争抢资源。现在水面只绘制一次并保持静止，仅在镜头移动或地图变化时才重绘。瀑布保留原有的层次质感，复杂地图的操作也更加流畅。
- **无法运行 3D 的浏览器不再停留在空白页面。** 此前 3D 视图启动失败时屏幕会一片空白且无法返回；现在应用会提示 3D 视图无法启动并自动回到 2D 视图。会话中途图形环境重置时，视图会暂停并在浏览器恢复后继续。
- **没有可用图形加速的机器上，3D 视图大幅减负。** 在以软件方式渲染 3D 的电脑上，原有设置（柔和阴影、额外抗锯齿、全分辨率）可能导致每帧耗时数秒、处理器满载。现在会检测这类机器并改用更朴素但流畅的画面：不再渲染阴影，使用标准抗锯齿和标准分辨率，也不播放相机进场动画。
- **没有可用图形加速的机器上，2D 地图同样减负。** 浏览器以软件方式渲染时，地图的每一个像素都由处理器绘制，而高分辨率屏幕需要的像素是普通屏幕的四倍。现在这类机器按标准分辨率绘制地图：平移、缩放和绘制明显更流畅，高分辨率屏幕上画面略微柔和，普通屏幕上没有变化。导出的图片和分享图在两种情况下都保持原有分辨率；若更看重清晰度，可以把 3D 画质设置固定为「完整」，地图会恢复原先的精细度。
- **自动修剪只作用于笔画真正改变的地方。** 开启自动修剪时，绘制可能改动它从未触碰的边角：相隔一格、背面朝向空地的方块，会被笔画的边界扫描修剪。现在只有笔画确实改变了某个边角的周边环境时才会修剪它，刻意保留方角的边角不再被改动。
- **在已修剪的地形上叠加新层时，下层的修剪会随笔画即时恢复。** 此前把已修剪内角周围的山体加高后，旧的圆角块会留在加高后凹口的底部，看起来像一块多余的楔子，既无法修剪掉也无法修复。现在画笔经过、山体高过圆角块的那一刻就会将其移除，无需等到松开指针，与方块加高时自动清除自身修剪边缘的行为一致。
- **高墙的内角可以修剪。** 此前对叠了两层以上的山体凹口做边缘修剪没有任何效果。现在修剪会生成一块贯穿凹口整个高度的圆角，与外角修剪一直以来对整列生效的方式一致；两侧墙体高度不同时，按两侧共有的高度修剪。
- **任意地址下都能导出带分享码的图片。** 分享码的校验哈希此前依赖仅在安全页面提供的浏览器功能，通过普通地址访问时导出会直接失败。现在哈希在任何环境都能计算，导出的分享码两种方式完全一致。
- **像素画、文字等图片类生成地图恢复了分享码导出。** 分享码此前会附带生成配方备注，而图片类配方包含源图片本身，远超分享码的容量，导致所有由图片生成的地图导出失败。现在图片配方不再写入分享码（地图本身就是这幅图片），任何过大的配方都会整体省略而不是导致导出失败，这类地图编码后足够小，可以使用最稳健的码密度。
- **新手引导期间应用保持静止。** 引导进行时，点击不再穿透暗色遮罩触达地图和背后的控件，新用户不会在引导结束前误编辑岛屿或切换模式。跳过按钮和 Esc 仍可随时退出引导。
- **引导中关于缩放的描述已更正。** 相机步骤现在写明 Ctrl + 滚轮：在许多触控板和平滑滚动的鼠标上，直接滚动是平移地图，旧文案指向的手势并不能缩放。
- **友邻中心在 3D 视图中恢复了应有的高度。** 它本是高出地面一层的台基，2D 视图和图层面板也一直按一层统计；3D 视图现在将它绘制为实心的一层底座，与相邻的一层地形齐平，不再平贴于地面。
- **欢迎卡片不再出现多余的焦点框。** 用于标示键盘焦点的深色描边，此前在面板自行获得焦点时也会出现（首次启动或点击面板时）；现在仅在通过键盘移动焦点时显示。
- **图层面板的方形布局不再遮挡底行。** 表示列表可以继续滚动的底部渐隐，此前在切换到方形布局后偶尔残留，盖住已经完整显示的地面一行；现在内容不再溢出时它会立即消失。
- **路面始终跟随它铺设的地面。** 此前清除路面下方的山体后，路面会悬空残留。现在地面整体降低时路面随之下移；地面变得高低不一时路面被移除，与游戏内在路面下方新建山体时的处理一致。路面在笔画进行过程中即随地面变化：所处地面不再合法时立即移除，恢复合法后立即放回，无需等到松开指针。所有改动地形的方式都遵循这一规则：画笔、橡皮、智能建造与 AI 助手。
- **在已有路面上铺设其他路面时会干净地替换。** 此前跨材质覆盖铺设可能破坏地图数据：同一格上叠放多块路面，无关位置的路面消失，撤销后回到从未出现过的状态。现在一次落笔先移除被覆盖的路面再铺设新路面，作为一步完成，撤销会准确回到落笔前的地图。
- **路面在 3D 视图中平贴地面。** 路面是覆盖在地面上的一层表面。3D 视图现在将它直接绘制在地形表面，边缘的柔和过渡与 2D 视图一致，不再是一块凸起的板材，同一高度的路面也不会再显示出高低差。
- **高瀑布脚下可以挖出水潭。** 此前把瀑布前方的地面改为水体会被底座规则拒绝：水体计入的支撑比它替换的地块低一层，瀑布自身的封口山体因此失去底座。现在水体按其水面高度为相邻地块提供支撑，与游戏内开凿瀑布的方式一致；水面上仍然不能建造任何东西。
- **在没有可用图形加速的电脑上，编辑器的速度大幅提升。** 此前地图每一帧都会把整个画面绘制两遍，无人操作时也持续重绘；在没有图形加速的环境下，每次重绘还会把每一块填充色重新换算一遍。现在地图只绘制一次，且只在内容发生变化之后绘制，颜色也直接沿用已有的结果。在这类电脑上，密集岛屿的平移与缩放、绘制地形、大面积铺设路面以及导出分享图片都明显更快，无人操作时地图也不再自行重绘。3D 视图中，场景出现后的第一次编辑不再卡顿一秒以上，转动镜头时也不会因为岛屿的新部分进入画面而停顿。画面呈现的内容没有任何变化。
- **3D 中的区域高亮贴合切角后的地面。** 在切圆过的转角处，已选区域的白色覆盖仍停在原本方块的高度，于是悬在切角露出的台阶、水面或草地上方。现在它逐角贴合该处真正绘制的表面，工具预览、提交与错误闪烁以及迷宫路线也一并修正。铺在地面水池上的覆盖层也改为贴在水面上，而不再没入水下。
- **旁边有树时，山体的内凹转角也能修圆了。** 此前只要附近地面上立着物件，修整山体内凹转角就会提示无法在有物件的格子上施工，哪怕补出的那一小块与物件相距甚远。现在只核对补出的那四分之一格，只有物件确实立在其中时才会拒绝。

- **新的默认键位，与游戏操作对齐。**地形工具按工具栏顺序排布在数字键上，WASD 平移地图。所有命令仍可重新绑定，原有键位作为预设保留。
- **保存与分享合并为一个窗口**，分为三部分：继续编辑、分享图片、查看建造清单。
- **3D 视图以正视角打开**，与 2D 视图一致，并且打开更快：在使用 2D 视图期间即在后台预取其场景。开场镜头动画过程中操作镜头会立即落到最终视角，而不是等动画播完才响应。
- **满地图编辑更流畅**，在存在大量选中物件时尤为明显。每笔背后的承重检查开销降至原先的约五分之一，3D 水面动画也改由显卡计算，不再逐帧重算。
- **框选区域在 3D 中更清晰**，改用白色绘制，不再是绿底上的绿色。

### 修复

- **笔刷预览与实际落笔一致。**预览贴合所悬停的表面，磨圆该笔真正会磨圆的边角，并将待放置物件绘制为一个整体而非多个部件的堆叠。
- **水会顺着所经过的地面走**，除非手动锁定了图层。
- **山体与水体相接处的切角会朝向该山体**，使交界读作一条连续的线；两处岸线在一点相接时也会正确焊合。
- **含半格跨越结构的存档在导入时不再丢失撤销历史。**
- **生成面板的配方输入框改为一条书写线。**空白处位置与长度不随数字增长而改变，光标高度与相邻数字一致。
- **道路的圆角在生成或智能建造之后可能保留旧形状**，直到附近其它内容被重绘。
- **生成器运行失败不再导致后续生成全部退回主线程**，此前会使该次会话中之后每次操作都变慢。
- **数字快捷键按物理按键触发**，不受键盘布局输出字符的影响。
- **光标反映的是当前所用工具**，而不是刚刚离开的那个。

## [0.1.1645] - 2026-07-30

谷地工坊是一个在浏览器里运行的《星布谷地》地图规划工具。先在这里规划一座岛，再到游戏里照着搭。所有数据都不上传，也不需要账号。

### 新增

- **同一张地图，两个编辑视图。**2D 和 3D 编辑的是同一张网格，每件工具在两边都能用。编辑到一半切换视图，地图、选中项和历史记录都保持不变。3D 视图另有水面动画、柔和阴影，每件摆放的物品都有对应的模型。
- **地形笔刷自带规则检查。**自由笔刷、直线、曲线、矩形、圆形，另有笔刷大小调节。画出游戏里不允许的结果，这一笔会当场撤销，编辑器会说明是哪条规则没通过。
- **物品在落地之前就检查。**放不下的位置会被直接拒绝，而不是先放下再收回。桥在两岸平整且高度相同时会自动对齐就位。
- **62 件可摆放物品**：小屋、设施、桥梁、坡道、树木与花草，另有两种道路，像笔刷一样直接画。物品吸附网格，点击旋转，拖动换位置。
- **边角切割。**可以一次修一个山角，也可以打开自动修边，边画边修，形状在切角和圆角之间选择。
- **八个图层**，每层都有独立的显示与锁定开关；橡皮每次削掉一层。
- **两种生成器，同一个配方号。**随机会设计一座有人住的岛：主题各异的街区、能走上去的台地、逐级流入海里的河道、两岸等高处的桥，以及连到每一户的道路。迷宫则把可建造的地面铺成通道。同一个号码永远生成同一张地图，所以喜欢哪个号码，直接发给别人就行。
- **自然度滑杆**，同一个配方可以从方正一路调到自然，另有最大高度限制。
- **分享图就是地图本身。**地图可以导出成一张图片，上面带有可见的 PetitGlyph 色带。把这张图片放回编辑器，就能一格不差地还原出这座岛。导入时会先校验，图片损坏到读不出来时会明确告知。
- **JSON 存档与读取**、可分节导出的 JSON，以及能把旧存档升级到当前版本的存档格式。
- **自动保存**在你自己的浏览器里，下次回来时会询问是否恢复。
- **可选的 AI 智能体。**密钥用你自己的，加密保存在你的设备上，支持九家服务商，也包括任何 OpenAI 兼容接口。它先写出方案，走的是和你的画笔同一套规则，每个阶段都留成一个可以回退的节点。它动手之前问得多勤，由你决定。
- **可交互的快捷键页面。**所有命令都画在一张键盘上，含修饰键分层和小键盘。点一个键就能看到它的作用，录一组新的组合键即可改绑，也可以搜索还没有绑定按键的命令。绑定会保存下来，并支持导出和导入 JSON。
